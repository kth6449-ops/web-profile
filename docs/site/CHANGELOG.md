# 변경 이력

## v5.0 · 2026-09-26

- 사용자 첨부 네 HTML의 최신 원고 적용
- 모든 페이지와 편집 화면에서 사이트 로고 제거 및 메뉴 재배치
- index와 동일한 본문 최대 너비·좌우 여백 적용
- 이야기 상단을 전체 폭으로 확장하고 데스크톱 제목 크기를 가용 너비에 맞춰 조정
- 네 가지 태도 라벨의 글꼴·크기·행간을 본문과 통일
- 배움 문단의 중복 문장 정리
- 폴더 이름을 web-profile v5.0으로 통일


## v4.0 · 2026-09-26

- 첨부된 v2.0의 나의 이야기 본문과 네 장의 구성을 복원
- 도입, 배움, 선택 문단에 현재 첫 페이지의 표현을 소폭 반영
- 나의 이야기의 게시글 목록·작성 기능을 제거하고 편집 화면의 게시 대상을 나의 생각·생각을 실현하기로 정리
- 전체 페이지 버전 표기와 안내 문서 갱신

## v3.0 · 2026-09-26

- 사용자가 수정한 `index.html`의 철학·소개·메뉴 문구를 전체 페이지에 반영
- 첫 페이지의 사진 너비를 이전 배치의 약 75%로 조정하고 클릭 시 작은 움직임 추가
- `story.html`, `notes.html`, `toolbox.html`을 글 목록과 상세 보기 형태로 통일
- LinkedIn·Tistory 고정 소개와 전역 플랫폼 링크 삭제; 관련 URL은 글마다 선택 입력
- `editor.html`에서 글·대표 이미지·본문 이미지 작성, 미리 보기, 수정, 삭제 구현
- 브라우저 저장 후 `posts.js`를 내려받아 공개 글 파일을 갱신하는 편집 흐름 추가
- 기존 이야기 한 편, 생각 세 편, 제작 기록 두 편을 새 원고 구조로 정리

## v2.0 · 2026-09-26

- 사진 중심의 간략한 프로필, 네 가지 태도의 이야기, 나의 생각과 도구 소개로 네 페이지 구성

주요 구조와 기능 변경은 다음 주 버전, 문구·여백·오탈자 수정은 다음 부 버전으로 기록합니다.

# 김태현 개인 웹페이지 · v5.0

## 처음 열기

압축을 모두 해제하고 `index.html`을 열면 네 페이지를 볼 수 있습니다. HTML 파일과 `assets`, `images` 폴더는 같은 위치에 두세요.

글 작성까지 사용할 때는 Windows에서 `start_windows.bat`를 두 번 클릭하세요. Python이 설치되어 있으면 브라우저가 자동으로 열립니다. 검은 터미널 창을 닫으면 미리 보기 서버도 종료됩니다. 배치 파일이 작동하지 않으면 VS Code에서 이 폴더를 연 뒤 **터미널 → 새 터미널**을 선택하고 `python preview.py`를 입력하세요. 브라우저의 `file://` 방식은 페이지마다 저장 공간을 다르게 취급할 수 있어 글 편집에는 로컬 서버 방식을 권합니다.

## 페이지와 파일

| 파일 | 용도 |
|---|---|
| `index.html` | 나의 철학: 프로필 사진과 간결한 소개 |
| `story.html` | 나의 이야기: 배움·연결·선택·실행의 네 장으로 구성한 소개 |
| `notes.html` | 나의 생각: 관찰과 질문의 게시글, 분류 필터 |
| `toolbox.html` | 생각을 실현하기: 도구와 실험의 게시글 |
| `editor.html` | 글 작성·수정·삭제, 이미지 선택, 미리 보기, 게시 파일 내려받기 |
| `assets/posts.js` | 나의 생각·생각을 실현하기 페이지에 나타나는 **공개 글 원본** |
| `assets/style.css` | 공통 디자인, 사진 크기와 움직임 |
| `assets/app.js` | 메뉴, 글 목록, 편집 화면 동작 |
| `preview.py`, `start_windows.bat` | 로컬 미리 보기 시작 |
| `images/` | 프로필 사진과 기존 바다 유화 |

## 새 글 올리기

1. `notes.html`, `toolbox.html` 중 원하는 페이지에서 **+ 새 글 작성**을 누릅니다.
2. 제목, 한 줄 소개, 본문을 입력합니다. 대표 이미지와 본문 이미지(최대 4장), 관련 URL은 선택 사항입니다. 이미지는 JPG·PNG·WebP를 사용할 수 있으며 한 장당 10MB 이하입니다.
3. **미리 보기**로 확인한 뒤 **이 브라우저에 저장**을 누릅니다. 이때 저장한 내용은 현재 브라우저에서만 보입니다.
4. 오른쪽의 **게시 파일 내려받기**를 눌러 `posts.js`를 받습니다.
5. 다운로드 폴더의 `posts.js`로 사이트 폴더 안의 `assets/posts.js`를 **교체**합니다. 이미 같은 이름의 파일이 있으므로 이때 **덮어쓰기**를 선택하세요.
6. 페이지를 새로고침하여 확인하고, 온라인 사이트를 운영한다면 수정된 사이트 파일을 다시 배포합니다. 이 과정을 거쳐야 다른 사람도 새 글을 볼 수 있습니다.

이미지는 작게 변환되어 내려받은 `posts.js` 안에 포함되므로 새 이미지 파일을 따로 옮길 필요가 없습니다. 글이 많아져 이미지 때문에 브라우저 저장 공간이 부족하면 이미지 수나 크기를 줄이고 게시 파일을 자주 내려받으세요. 브라우저의 사이트 데이터를 지우면 게시 파일에 반영하지 않은 글은 사라질 수 있습니다.

**중요:** 정적 HTML에는 방문자 모두에게 즉시 게시하는 서버 기능이 없습니다. 이 편집 화면은 사이트 소유자가 글을 작성하고 게시 파일을 만드는 도구입니다. 온라인에서 로그인 후 바로 게시하는 방식은 향후 서버·인증·저장소를 연결해야 합니다.

## VS Code에서 직접 텍스트 수정

- 첫 페이지의 문구: `index.html`에서 보이는 태그 안의 글자를 바꿉니다.
- 다른 페이지의 제목과 소개: 각각 `story.html`, `notes.html`, `toolbox.html`의 `<main>` 안에서 바꿉니다.
- 나의 이야기 본문: `story.html`의 `chapter-1`부터 `chapter-4`까지 각 `<h2>`와 `<p>` 안의 글자를 바꿉니다.
- 기존 게시글의 제목·본문: `assets/posts.js`에서 해당 글을 찾아 바꿉니다. `body`는 백틱(`) 사이의 글이며 빈 줄로 문단을 나눕니다. `## 소제목`, `- 목록` 형식을 사용할 수 있습니다.
- 사진 크기: `assets/style.css`의 `.profile-portrait{width:75%...}`를 수정합니다. 예: `65%`는 더 작고 `85%`는 더 큽니다.
- 모든 수정 뒤 **Ctrl+S**로 저장하고 브라우저에서 **Ctrl+F5**로 새로고침합니다.

기존 글을 편집 화면에서 수정해 저장했다면 마지막에 `posts.js`를 다시 내려받아 교체하세요. 저장된 로컬 수정본이 공개 원본보다 우선 보이기 때문입니다.

## 버전

v4.0에서는 첨부된 v2.0 원고를 바탕으로 나의 이야기를 네 장의 소개 페이지로 복원했습니다. 글 작성 기능은 나의 생각과 생각을 실현하기에서 사용합니다. 언어 전환은 한국어만 활성화되어 있습니다.


## v5.0 화면 조정

폴더 이름은 `web-profile v5.0`입니다. 사이트 로고를 제거하고 모든 페이지의 가로 폭과 여백을 통일했습니다. 이야기 제목은 데스크톱에서 한 줄에 맞춰 크기를 조절하며, 모바일에서는 읽기 쉬운 크기를 유지하도록 자연스럽게 줄바꿈합니다. 수정한 CSS와 JavaScript까지 포함되므로 전체 폴더를 사용하세요.

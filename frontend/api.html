프론트엔드·백엔드 연동 실습

지금 보고 계신 이 페이지는 Vercel에 올라간 HTML 파일입니다. 제 프로필 정보를 돌려주는 FastAPI 서버는 Render에 따로 올라가 있습니다. 아래 버튼을 누르면 이 브라우저가 Render의 서버를 직접 호출하고, 돌아온 프로필 데이터를 그대로 보여줍니다.

Frontend · VercelBackend · FastAPI on RenderDocs · Swagger UI

무엇이 어디에 있나

소개 페이지(index.html)의 내용은 고정된 HTML이고, 이 페이지는 같은 내용을 백엔드가 실시간으로 돌려주는지 확인합니다. 두 서비스는 서로 다른 도메인에 있어, 백엔드가 출처를 허용(CORS)해야만 호출이 통과합니다.

직접 호출해 보기

버튼을 누르면 실제 HTTP 요청이 나갑니다. 상태 코드와 응답 본문이 그대로 표시됩니다.

백엔드 서버를 깨우는 중입니다. 잠시만 기다려 주세요.
버튼을 누르면 요청과 응답이 이곳에 표시됩니다.

Render 무료 플랜은 15분간 요청이 없으면 서버가 잠듭니다. 첫 호출은 최대 1분까지 걸릴 수 있습니다 — 이 페이지는 열릴 때 서버를 미리 깨웁니다. 프로필 데이터는 코드에 담겨 있어 서버가 다시 깨어나도 그대로 유지됩니다.
